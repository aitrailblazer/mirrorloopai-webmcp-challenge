Most assistants can discuss a decision. But without a site-owned contract, they
must reconstruct the application from page text. MIRROR//LOOP changes that.

On the live site, eleven typed WebMCP tools register over the same experience a
person can use directly. The Agent State rail makes every call visible.

The agent starts a private reflection and asks for only the current question.
The page—not the model—owns the session state.

When two answers feel close, the agent can compare them in the site's own
language. It clarifies the difference, but it does not rank, select, or record
either choice.

Now watch the safety boundary. An unconfirmed answer is rejected. The model
cannot quietly advance the reflection.

Only after the person explicitly confirms does the browser save the answer and
move to the next question.

For this demonstration, the remaining choices were confirmed in advance. All
twelve answers now exist in browser-local state.

The same deterministic scorer used by the direct interface now produces
Horizon Signal. The agent guides the workflow; it does not invent the result.

Before changing anything, a what-if preview can test one alternative. It shows
the projected difference, while the saved answers and visible result remain
untouched.

The agent can retrieve any curated public card from the complete 144-card
matrix.

It can also identify a relevant digital edition. The response contains no
price and cannot touch the cart, create Checkout, or pay.

With one more explicit confirmation, the user can download a Markdown or JSON
dossier. The export stays in the browser; no email or account is required.

MIRROR//LOOP removes navigation and interpretation friction while meaning,
identity, communication, and payment remain under human control. Try
mirrorloopai.com and inspect the MIT-licensed source on GitHub.
