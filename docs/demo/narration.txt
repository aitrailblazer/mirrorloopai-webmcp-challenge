We are MIRROR//LOOP, an independent AITrailblazer project. Our WebMCP Challenge entry shows how site-owned tools can help a person find one clear next step without giving up control.

Stress narrows attention while generic advice and AI-generated pseudo-solutions multiply. MIRROR//LOOP reveals a response pattern and turns it into one practical action.

The website challenge is comprehension and navigation. A person faces twelve questions and 144 cards, while a generic agent must infer meaning from page controls.

WebMCP exposes named, site-owned tools with validated inputs and structured results. The agent uses the website's contract instead of guessing from the page.

Our entry turns MIRROR//LOOP into a shared human-agent experience. The agent clarifies and navigates; the browser scores; the person confirms every choice.

Eleven tools register over the same experience a person can use directly. The Agent State rail makes each call visible without opening DevTools.

The agent starts a private reflection and requests only the current question. The page—not the model—owns the session state.

When two answers feel close, the agent compares them in the site's own language. It clarifies the difference but does not choose.

An unconfirmed answer is rejected. The model cannot quietly advance the reflection.

Only after explicit confirmation does the browser save the answer and move forward.

With twelve confirmed answers, the same deterministic scorer used by the direct interface produces Horizon Signal. The agent does not invent the result.

A what-if preview can test one alternative without changing the saved answers or visible result.

The agent can retrieve any exact public card from the complete 144-card matrix.

It can identify a relevant digital edition, but it cannot change the cart, create Checkout, or pay.

With one more confirmation, the user downloads a local Markdown or JSON dossier. No email or account is required.

MIRROR//LOOP removes comprehension and navigation friction while meaning, identity, communication, and payment remain under human control.
